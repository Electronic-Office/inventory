# EO Project Inventory — phone launcher

Installable home-screen app (PWA) for the EO Project Inventory Rewst app. Opening this site on a phone prompts to install it;
the installed icon opens the Rewst app (`app.rewst.ai/.../apps/eo-project-inventory`). No data, no credentials: it only links out.

Source of truth: `aiprojects/project-inventory/launcher/` (built by EO Automation). Served by GitHub Pages from `main`.
